# Yating Wu

[Academic website](https://yatingwu.info/) · [Research projects](https://yatingwu.info/research/)

Research in natural language processing, Questions Under Discussion, LLM agents, and multimodal scientific reasoning.

## Projects

Each project page links to the paper, available code or data, examples, and a BibTeX citation.

| Project | Research contribution | Paper |
| --- | --- | --- |
| [MQUD](https://yatingwu.info/multimodal-qud/) | A dataset of questions evoked by scientific figures, with answers from the papers | [Paper](https://arxiv.org/abs/2604.23733) |
| [ContextWeaver](https://yatingwu.info/contextweaver/) | Memory construction for LLM agents using dependencies between reasoning steps | [Paper](https://arxiv.org/abs/2604.23069) |
| [QUDsim](https://yatingwu.info/qudsim/) | A discourse similarity metric for comparing how texts develop their ideas | [Paper](https://openreview.net/forum?id=zFz1BJu211) |
| [QSalience](https://yatingwu.info/qsalience/) | Question salience annotations and models that predict how much an answer would help a reader | [Paper](https://aclanthology.org/2024.emnlp-main.1114/) |
| [QUDeval](https://yatingwu.info/qudeval/) | Human evaluation criteria and annotations for QUD discourse parsing | [Paper](https://aclanthology.org/2023.emnlp-main.325/) |
| [ElabQUD](https://yatingwu.info/elabqud/) | Annotations connecting added explanations to implicit questions in text simplification | [Paper](https://aclanthology.org/2023.emnlp-main.336/) |
| [QUD dependency parsing](https://yatingwu.info/qud-parsing/) | A discourse parser that links sentences through questions and answers | [Paper](https://aclanthology.org/2023.findings-acl.710/) |
| [Bilingual disfluencies](https://yatingwu.info/bilingual-disfluencies/) | An analysis of word predictability and linguistic features in monolingual and bilingual speech | [Paper](https://openreview.net/forum?id=rrNAqNYRLA) |
